# 어디에 무엇을 요청할 것인가

`docs/data-sources.md` 가 "지금 무엇을 쓰고 있는가" 라면, 이 문서는
"무엇을 더 받아야 하고 누구에게 요청하는가" 입니다.

조사일: 2026-09-02. **연락처는 아래 "연락처" 절에 적힌 방법으로 브라우저로
직접 확인했습니다.** 사이트 내용은 바뀔 수 있으니, 보내기 전에 한 번 더
확인하세요.

---

## 요약 — 세 갈래로 갈립니다

| | 무엇 | 필요한 것 | 메일 |
| --- | --- | --- | --- |
| **A** | 공공데이터 (체육시설·팀등록·날씨) | **키 발급만** | 불필요 |
| **B** | 상용 API (네이버·유튜브) | **키 발급만** | 불필요 |
| **C** | 여자야구 경기 일정·결과·기록 | **이용허락** | **필요** |

**중요한 발견:** A 군은 이용허락범위가 "제한 없음" 이라 **메일을 쓸 필요가
없습니다.** 회원가입하고 활용신청만 하면 됩니다. 그래서 C 군에 보내는 메일은
**그 기관만 가진 것**(여자야구 경기 일정·결과·선수 기록)만 요청하면 됩니다.
팀 목록과 구장은 A 에서 정당하게 받을 수 있으므로 요청 목록에서 뺍니다.

## A. 공공데이터포털 — 키만 발급받으면 되는 것

전부 `data.go.kr` 한 계정으로 처리됩니다. 회원가입 → 데이터 상세 →
**활용신청** → 승인(대개 자동/즉시, 일부는 1~2일).

### A-1. 전국체육시설 정보 (서울올림픽기념국민체육진흥공단)

- 제공: 시설명, 시설구분, 업종, 주소, 우편번호, 소유주체, 담당부서
- 형태: **오픈API**
- 쓰임: 지금 `venue-demo-*` 로 채워 둔 구장을 **실제 구장으로 교체**
- 주소: https://www.data.go.kr/data/15113986/openapi.do

같이 볼 것 — **전국체육시설표준데이터** (표준 스키마, 지자체 통합):
https://www.data.go.kr/data/15096288/standard.do

### A-2. 대한체육회 스포츠지원포털 팀등록정보

- **179,559건**, 연 1회 갱신, **이용허락범위 제한 없음**, 무료
- 컬럼: 팀명, 등록연도, 등록일, **종목**, **세부종목**, **종별구분**,
  시도, 관련 홈페이지 URL
- 형태: CSV + **오픈API**
- 쓰임: `종목 = 야구` + `종별구분` 으로 **등록된 여자야구 팀 명단**을 추릴 수
  있는지 확인할 것. 되면 팀 데이터를 긁지 않고 정당하게 채웁니다.
- 주소: https://www.data.go.kr/data/15052697/fileData.do

**주의:** 상세 페이지에 *"종별구분, 세부종목 항목 중 데이터값이 공란인
부분은 미집계 데이터"* 라고 적혀 있습니다. 여자야구가 실제로 구분되어
들어있는지 **받아서 직접 확인**해야 합니다. 안 들어있으면 이 경로는 없는
것이고, 그때 C-1 의 요청 목록에 팀 명단을 다시 넣습니다.

### A-3. 기상청 단기·중기예보

- 이미 어댑터가 있고 **키만 없습니다** (`docs/data-sources.md` 참조)
- 쓰임: 경기일 날씨. D+0~2 상세, D+3~10 범위 — 그 이상은 만들지 않습니다

### A-4. 참고만 — 대한체육회 국제행사 정보

국제 대회 일정. 여자야구가 포함되는지 불확실하니 확인 후 판단.
https://www.data.go.kr/data/15108399/fileData.do

## B. 상용 API — 키만 발급받으면 되는 것

| | 어디서 | 쓰임 |
| --- | --- | --- |
| 네이버 검색 API | `developers.naver.com/apps` → 애플리케이션 등록 → **검색** 선택 | 뉴스 제목·매체·발행시각·원문 링크 |
| YouTube Data API | Google Cloud Console → 프로젝트 → YouTube Data API v3 사용 설정 → 사용자 인증 정보 | 공식 채널 영상 메타데이터 |

**둘 다 본문·이미지를 복제하지 않고 링크와 메타데이터만 저장합니다** —
`docs/data-sources.md` 3절의 결정 그대로입니다.

**키를 저장소에 넣지 마세요.** `--dart-define` 또는 GitHub Secrets 로만
넣습니다. 이건 예외 없는 규칙입니다.
