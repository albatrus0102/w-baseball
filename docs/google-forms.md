# Google Forms 연동

자동 수집이 막혀 있는 동안(그리고 막힌 뒤에도) **사람이 넣는 경로**가 필요합니다.
느리지만 합법이고, 출처가 명확하며, 틀렸을 때 고칠 방법이 있습니다.

서버를 두지 않으므로 Google Forms → Google Sheets → 사람 검수 → 배포본
갱신이라는 흐름을 씁니다.

---

## 1. 앱에 가짜 URL이 없는 이유

`FormsConfig` 의 다섯 URL은 **기본값이 전부 빈 문자열**입니다.

URL이 비어 있으면 해당 항목은 앱에서 **"준비 중"으로 표시되고 눌리지 않습니다.**
그럴듯한 `https://forms.gle/xxxxx` 를 넣어두는 것보다 정직합니다 — 눌렀는데
404가 뜨면 사용자는 앱 전체를 못 믿게 됩니다.

폼을 실제로 만든 뒤에 값을 넣으세요.

---

## 2. 폼 5종

| 환경 변수 | 폼 | 용도 |
| --- | --- | --- |
| `WB_FORM_TEAM_REGISTRATION` | 팀 등록 | 새 팀을 목록에 추가 |
| `WB_FORM_SCHEDULE_CHANGE` | 일정 변경 | 경기 시각·장소 변경, 우천 연기 |
| `WB_FORM_RESULT_SUBMISSION` | 결과 제출 | 경기 종료 후 스코어 |
| `WB_FORM_DATA_CORRECTION` | 정정 요청 | 잘못된 기록 신고 |
| `WB_FORM_PRIVACY_REMOVAL` | 개인정보 삭제 요청 | 본인 정보 삭제 |

마지막 폼은 선택이 아닙니다. 사람 정보를 조금이라도 다루면 **삭제 요청 창구가
있어야** 합니다.

---

## 3. 각 폼에 넣을 항목

### 공통

- 제보자 연락 방법 — **선택 항목으로**. 필수로 만들면 개인정보를 필요 이상으로
  모으게 됩니다.
- 근거 링크나 사진 — 검수자가 확인할 수 있어야 합니다.
- 자동 채워지는 숨김 항목: `entityId`, `sourceUrl` (4절)

### 팀 등록

팀명, 약칭, 흔히 쓰는 다른 표기(**별칭 — 매우 중요**), 활동 지역(시·도),
홈 구장, 소속 리그, 공개 채널 링크.

> 별칭을 여기서 받아두면 뉴스 정규화 단계의 미해결 별칭이 크게 줄어듭니다.

### 일정 변경 / 결과 제출

경기 식별(날짜 + 양 팀), 변경 내용 또는 최종 점수, 이닝별 점수(선택),
경기 상태(정상 종료·콜드·우천 취소·몰수).

> 이닝 합계와 최종 점수가 맞는지는 검증기가 확인합니다.

### 정정 요청

무엇이 틀렸는지, 올바른 값, 근거.

### 개인정보 삭제 요청

대상, 본인 확인 방법, 삭제 요청 범위.

### 받지 말아야 할 것

전화번호, 주소, 개인 이메일, **정확한 생년월일**, 미성년자 사진.
폼에 칸을 만들지 마세요. 칸이 있으면 채워집니다.

---

## 4. 사전 채우기 (미리 채워진 링크)

앱에서 정정 요청을 열 때, 어떤 레코드인지 자동으로 채워주면 제보 품질이
크게 올라갑니다.

Google Forms에서 **"미리 채워진 링크 가져오기"** 를 누르면 이런 URL이 나옵니다.

```
https://docs.google.com/forms/d/e/FORM_ID/viewform?usp=pp_url&entry.123456789=값
```

`entry.123456789` 부분이 필드 id입니다. 이 값을 넣으세요.

```
WB_FORM_FIELD_ENTITY_ID=entry.123456789
WB_FORM_FIELD_SOURCE_URL=entry.987654321
```

이 값이 없어도 폼은 열립니다. 그냥 비어 있는 채로 열릴 뿐입니다.

두 필드는 Google Forms에서 **응답자에게 보이지 않게** 할 수 없으므로, 짧은 텍스트
항목으로 만들고 설명에 "자동으로 채워집니다. 수정하지 마세요"라고 적어두세요.

---

## 5. 폼 설정

- **로그인 요구: 끄기.** 로그인을 요구하면 Google 계정 정보를 받게 되고, 제보
  장벽도 높아집니다.
- **이메일 주소 수집: 끄기.** 위와 같은 이유.
- **응답 편집 허용: 켜기.** 제보자가 스스로 고칠 수 있게.
- **응답 사본 전송: 선택 제공.**

---

## 6. 검수 흐름

```
폼 응답 → Google Sheets
   ↓  사람이 확인 (근거 링크, 상식적 타당성)
   ↓  CSV로 내보내기
   ↓  public-data/ 형식으로 변환 (출처 = 제보, reviewStatus = reviewed)
   ↓  python scripts/validate/validate_data.py public-data
   ↓  통과하면 커밋
```

원칙:

- **제보가 바로 게시되지 않습니다.** 사람이 승격시킵니다.
- 제보로 들어온 레코드의 `provenance` 는 제보임을 밝히고, 필요하면 근거 링크를
  `sourceUrl` 로 씁니다.
- **틀린 결과가 게시됐다가 고쳐지면** `_recordGameChanges()` 가 무엇이 바뀌었는지
  남깁니다. "어제 본 점수랑 다른데?"에 답할 수 있어야 합니다.
- 개인정보 삭제 요청은 **가장 먼저** 처리하세요.

---

## 7. 앱에서 보이는 모습

`lib/features/submissions/` — 더보기 → 제보.

- URL이 설정된 항목만 활성화됩니다.
- 폼은 허용 목록에 있는 도메인만 여는 WebView에서 열립니다
  (`lib/features/web_source/`).
- 경기 상세 화면에도 "정보가 잘못됐나요?" 진입점이 있고, 여기서 열면
  `entityId` 가 미리 채워집니다.
